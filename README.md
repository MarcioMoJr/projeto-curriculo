## 📖 Sobre o projeto

O **Projeto Currículo** é uma página web com o meu currículo pessoal.

## 📋 Seções do currículo

- 👤 **Dados pessoais** – minha foto, meu nome e o link do meu GitHub
- 🎯 **Objetivo** – busco oportunidades de estágio ou aprendiz na área de tecnologia
- 🎓 **Formação acadêmica**
- 💡 **Habilidades**
- 📚 **Cursos extracurriculares**

## 🛠️ Tecnologias

- **HTML5** – estrutura da página
- **CSS3** – estilização e layout
- **GitHub Pages** – publicação do site

## 📁 Estrutura do projeto

```
projeto-curriculo/
├── css/            # Folhas de estilo
├── img/            # Imagens
└── index.html      # Página do currículo
```

## 🚀 Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/MarcioMoJr/projeto-curriculo.git
```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

Ou, se preferir, acesse direto pelo site: [Projeto Curriculo](https://marciomojr.github.io/projeto-curriculo/)
